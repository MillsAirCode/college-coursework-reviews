## format

Each review hits:

- **what it was** — one paragraph on the assignment + what I shipped
- **what holds up** — patterns, decisions, structure I'd still write today
- **what I'd refactor** — concrete changes; libraries/idioms that aged badly
- **portfolio take** — keep, archive, or quietly link from a bullet
