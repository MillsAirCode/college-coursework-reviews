# CS470-II

## what it was

SNHU CS-470 (Full Stack Development II), spring 2024. Cloud computing course covering microservices, serverless architectures, containers, and AWS. The repo doesn't contain any actual code -- just a README with a course reflection essay and a PDF of the same content. It reads like a concepts-heavy class where the deliverable was a written reflection rather than a working project.

## what holds up

The reflection shows I actually understood the core cloud concepts. The containers vs serverless comparison is fair -- containers for predictable workloads, serverless for variable/spiky traffic. The cost analysis section (predicting Lambda invocation costs vs container provisioning) shows practical thinking beyond just memorizing buzzwords. The autoscaling and error-handling discussion with CloudWatch monitoring and retry mechanisms is accurate and reflects real operational thinking.

## what I'd refactor

The whole thing is just an essay. No Dockerfile, no Lambda function, no Terraform -- nothing tangible. The README is full of academic filler: "greatly expanded my understanding," "highly sought after in tech-driven fields," "paramount." It reads like someone trying to hit a rubric word count rather than document actual engineering decisions. I clearly didn't build anything deployable for this course, which is a shame -- cloud skills are only useful when you've actually shipped something to AWS.

## portfolio take

Archive. No code to show, just a reflection essay. Not worth keeping on a public profile.
